# 執事ロウレンス キャラクター正史

決定日: 2026-08-01

## 決定

Growlogueで `Cedric（セドリック）` として実装されていたハシビロコウの侍従を、
**Lawrence（ロウレンス）**へ改名する。

- Growlogueをロウレンスの正史・プロダクト上の出典とする。
- 表示名: `Lawrence（ロウレンス）`
- 役割: 寡黙で観察眼に優れ、確認と見守りを担うハシビロコウの筆頭執事
- 画像: `apps/web/public/images/companions/lawrence.webp`
- 中核コピー: 「騒がず、整えます。」

## 互換性

内部ID `character-attendant-cedric` は変更しない。
このIDは既存の `Character`、`CharacterState` と利用者の相棒選択を保持するための
レガシー識別子であり、画面へ表示しない。

旧画像 `cedric.webp` も、既存DB行やキャッシュが新しい `avatarUrl` へ更新されるまでの
互換資産として残す。新しい表示とデータ更新では `lawrence.webp` を使用する。

`ensureUserFoundation()` が実行されると、同一IDの `Character` 行は新しい表示名、説明、
画像URLへupsertされる。データ移行や相棒の再選択は不要。

## 外部展開との関係

- Growlogue: ロウレンスの正史。利用者に伴走する相棒として登場する。
- 凪の館: ロウレンスの日常と館の使用人を描く物語展開。
- SNS: 「本日のロウレンス」として、小さな困りごとへ応じる所作を発信する。
- LINEスタンプ: ロウレンスの確認、待機、見守りを会話で使える短い言葉へ変換する。

外部展開で新設定を追加するときは、Growlogue内の人格・役割と矛盾しないか確認する。
LINEスタンプの商品名・説明文はGrowlogueの広告として扱わず、キャラクター単体の商品として成立させる。

## 現在の境界

- この改名は表示名、説明、画像URL、関連テストを対象とする。
- 内部ID、DBスキーマ、保存済み相棒選択は変更しない。
- Lucien専用の感情別画像やAI文面を、ロウレンス用として流用しない。
- ロウレンス固有の口調・通知・感情差分は、別機能として設計・検証してから追加する。
