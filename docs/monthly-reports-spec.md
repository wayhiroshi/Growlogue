# Phase 5 月間レポート仕様

## 目的

本人が一か月の行動を責められることなく振り返り、積み重ねを一つの章として
認識できるようにする。既存のミッション、XP、能力、連続記録を都度集計し、
新しい入力や公開範囲は増やさない。

## 表示内容

- 月間の達成ミッション数、獲得XP、達成率
- 記録日数、Daily Clear日数、Perfect日数
- 日別の達成状態を示す月間カレンダー
- 能力別の獲得XP
- 最多達成Habitと現在の連続記録
- 集計結果から決まる月間称号
- 今月もっともXPが伸びた能力を示す重点テーマ
- 固定ルールから選ぶLucienの月間コメント

重点テーマはこのPhaseでは振り返り表示のみとし、XP倍率やミッション生成には
影響させない。AIは使用せず、称号、見出し、コメントを決定的なルールで選ぶ。

## API

### `GET /api/v1/reports/monthly?month=YYYY-MM`

- 本人認証必須。
- `month`省略時は、本人のタイムゾーンと午前4時境界から現在月を決める。
- 指定時は`YYYY-MM`形式だけを受け付ける。
- 本人のD1データだけを集計し、保存済みの月間スナップショットには依存しない。
- Habit名を含むため、共有APIや公開URLからは返さない。

## 称号

称号は月間集計だけから次の優先順で決める。

1. Perfect 8日以上: `Golden Gentleman`
2. Daily Clear 20日以上: `Steady Gentleman`
3. 達成ミッション20件以上: `Persistent Gentleman`
4. 達成あり: `First Footsteps`
5. 達成なし: `Quiet Chronicle`

称号は罰や降格として扱わず、達成の少ない月にも休息を肯定する称号を表示する。

## 受入条件

1. 当月と前後月をモバイル幅で移動できる。
2. 28日、29日、30日、31日の各月を正しい日数で表示できる。
3. 達成、XP、Daily Clear、Perfect、能力別XPが既存台帳と一致する。
4. 月間称号と重点テーマが同じ入力から常に同じ結果になる。
5. 未達成日を過度に赤くせず、空の月にも責めない固定コメントを表示する。
6. 未認証、無効な月、他人のデータへアクセスできない。
7. 週間レポートと能力画面から月間レポートへ移動できる。
